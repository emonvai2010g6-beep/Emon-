GG Mouse Pro — Super Fun Zone
================================

এই ZIP-এ GitHub Pages-এর জন্য তৈরি একটি মোবাইল-ফ্রেন্ডলি স্ট্যাটিক ওয়েবসাইট আছে।

ফাইল:
- index.html : ওয়েবসাইটের কাঠামো
- style.css  : ডিজাইন
- script.js  : জোকস, কুইজ, পোস্টার ও শেয়ার ফিচার

GitHub Pages-এ প্রকাশ করার নিয়ম:
1. GitHub-এ লগইন করুন এবং New repository চাপুন।
2. Repository নাম দিন: gg-mouse-pro-fun-zone
3. Public নির্বাচন করে Create repository করুন।
4. Add file > Upload files থেকে ZIP ফাইলটি আগে Extract করে এর ভেতরের চারটি ফাইল (index.html, style.css, script.js, README-BN.txt) আপলোড করুন। ZIP ফাইলটি সরাসরি আপলোড করলে সাইট চলবে না।
5. Commit changes চাপুন।
6. Repository-এর Settings > Pages খুলুন।
7. Build and deployment-এ Deploy from a branch নির্বাচন করুন।
8. Branch: main এবং folder: /(root) নির্বাচন করে Save চাপুন।
9. কিছুক্ষণ পর Pages পৃষ্ঠায় দেখানো URL-এ সাইট খুলবে।

নোট:
- এটি একটি স্ট্যাটিক সাইট; কোনো সার্ভার বা ডেটাবেস লাগে না।
- Google Fonts অনলাইনে লোড হলে বাংলা ফন্ট সুন্দর দেখাবে; অফলাইনে fallback font ব্যবহৃত হবে।
- এই প্যাকেজে Android APK নেই। APK ডাউনলোড বাটন যোগ করতে হলে আসল APK ফাইলের নিরাপদ ও প্রকাশ্য URL লাগবে।
